# Portfolio Site — Matheus (YUUQUE)

Este é um site estático simples feito para hospedar seu portfólio em GitHub Pages.

Deploy (passo rápido):
1. Coloque o conteúdo desta pasta na branch `gh-pages` ou na branch principal e ative GitHub Pages nas configurações.
2. Ajuste o email em index.html e o endpoint do Formspree no form.
3. Opcional: personalize cores e textos em style.css.

Tecnologias: HTML, CSS, JS (vanilla)
