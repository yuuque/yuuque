# YuuqueBot (exemplo)

Bot simples para Discord com comandos básicos.

Instalação:
1. Copie `.env.example` para `.env` e coloque o token do seu bot (DISCORD_TOKEN).
2. npm install
3. npm start

Comandos:
- !ping — responde Pong!
- !say <mensagem> — repete a mensagem
- !about — mostra info do bot

Deploy:
- Pode rodar em Railway, Render, Heroku ou uma VPS. Em plataformas como Railway, adicione a variável DISCORD_TOKEN no settings/environment.
